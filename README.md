# HIST 1301 Unit 1 Prototype

This package is the Version 1 prototype for the Unit 1 study system.

## Included
- `index.html` — Unit 1 dashboard
- `sections/1-1.html` — 1.1 Indigenous Cultures section
- `data/1-1.js` — all 1.1 Learn, Practice, and Multiple Choice content
- `js/app.js` — shared activity logic
- `css/styles.css` — shared responsive design

## 1.1 Modes
- Learn: 12 screens, each designed as a compact mini-lesson; 0–2 CFUs
- Practice: active recall with Got It / Need More Practice recycling
- Multiple Choice: 10 randomized questions from a 30-question bank
- No persistent student data in V1

## GitHub Pages
Upload the entire folder structure to the repository root. If GitHub Pages is configured to publish from the repository root, `index.html` becomes the homepage.
